# SAS Movie Genre Analysis 🎬

## Project Overview
This project analyzes the TMDB 5000 Movies dataset using SAS 
to explore genre-based frequency patterns in film production.
The analysis examines how often producers, executive producers,
or directors also appeared as cast members in their own movies.

## Objectives
- Analyze movie genre patterns using the TMDB dataset
- Calculate relative frequencies of cameo appearances by genre
- Develop a reusable SAS macro for genre comparison
- Identify patterns across different movie genres

## Dataset
- **Source:** TMDB (The Movie Database) — publicly available
- **Files:** tmdb_5000_movies.csv, cameo_Action.csv
- **Size:** 5,000 movies with genre, cast, and crew information

## Methods & Tools
- **Software:** SAS
- **Techniques:** SAS macros, frequency analysis, data merging
- **Key Macro:** Allows users to specify any list of genres 
  for comparison
